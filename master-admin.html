ℹ️ Passwords are stored securely on the server. Changes take effect immediately for the next login on all devices. No one can see the password — it can only be reset (see below).
❓ Forgot your password? How to reset
If you forget the Master Admin / Admin PIN, reset it via Google Apps Script (requires the Google account that owns the script):
  1. Open this site's Apps Script project (script.google.com → Kwelingo project).
  2. Click ⚙️ Project Settings.
  3. Scroll to Script Properties.
  4. Delete the MASTER_PIN and/or ADMIN_PIN row (click the delete icon), then Save.
  5. The PIN automatically returns to the default: Master Admin 5758, Admin 17081945. Log in with that, then change it again on this page.
No need to change code or redeploy. If you're unsure, contact whoever manages the Apps Script.
